# ClearView 0.3.2：统一阅读层级

2026-10-10 用户明确调整目标：不再要求百分百还原 Claude Desktop，由插件自主设计现代、流畅、易读的阅读视图。此文覆盖此前以 Code 页原型相似度验收的要求。截图中的“思考小行 / 工具带框加粗长条”交替必须消除。

## 视觉规则

- 阅读根区域透明，正文保持宿主字号、主文字色和 1.6 行高。正文与过程采用统一无衬线字体，以颜色、尺寸和段落留白分层；正文不额外放大。代码保留等宽字体。
- 思考、工具组、单个工具和普通记录使用 `Line`：32px 最小行高、5px/8px 内边距、相同图标槽与箭头、13px 加宿主 delta、正体、400 字重。长摘要可以换行。
- 模型重试和错误类记录使用独立 `Notice`：警告/错误图标、琥珀/红色细边框与浅底，标题和摘要分行，不并入普通工具组。历史重试保持记录措辞；详情可展开，保留原时间顺序。
- 过程行默认透明且无边框；悬停、键盘焦点、展开态使用同一套浅底。保留左侧折叠箭头，右侧不显示“展开 / 收起”文字；工具组不得单独更改背景、边框、字号或字重。失败只在语义位置用红色。
- 展开内容统一缩进和细引导线；工具详情、记录详情、计划使用同一套局部底色、边框、10px 圆角。整条对话不套额外容器。
- 完成轮次用 40px 的摘要入口，外观为透明底、无圆角、仅底边，保留状态、用时、步骤/工具数量和折叠箭头；收起后最终回答仍然可见。它与普通过程行属于不同层级。
- 运行状态采用小型活动环、扫光文字和次要计时。动效沿用 100/200/260ms 与逐词渐显，不因文本量降级 blur/shimmer。
- 用户气泡有独立底色和细边框；超过六行时末尾渐隐，展开/收起按钮位于视觉气泡内、复制座位外，复制原文不含按钮文字。
- 思考文字从80%不透明度起以180ms清晰化，保留1px初始模糊但不逐词排队；正文保留原350ms渐显。高速输出时可读性优先，不改变限高和跟随规则。

## 功能不回退

- 实时与展开的思考正文均保留 128px 限高滚动视口和完整原文。
- 自动跟随最新文本；滚轮、触摸、选区或焦点暂停。工具到来、下一步或轮次结束不丢手动回看的 DOM 和位置。旧实时视口可“结束回看”，普通历史思考不显示无效的跟随按钮。
- 保留整轮和工具组折叠、用户选择优先、选区/焦点保护、计划勾居中、复制和原生详情入口。
- 不发送模型消息、不创建会话、不改会话数据或宿主设置。预览使用隔离浏览器，正式更新走管理器流程。

## 验收

1. 三个既有会话的浅色、深色截图。思考/工具组的行高、padding、字重、字体、边框与圆角须通过 computedStyle 对比。
2. 折叠箭头真实可见、整行可命中，展开、收起、页签往返、复制可用；正文与过程色阶有区别。
3. 480px 同时检查 scrollWidth 和正文/阅读列相对可见区域的位置，禁止把“没有横向滚动条”当成没有裁切。
4. 真实浏览器合成连续输出：限高、尾随、暂停、跨步骤位置保留、恢复、减少动态效果、完整文本、历史额外渲染为零和 blur/shimmer 保留。
5. 本地测试、类型/构建、共享外部模块与浏览器语法检查。模拟流式数据不等于原生 WebView2 持续运行任务的性能验收。

颜色/字体变量保留历史 `--cc-*` 名称以兼容嵌入组件；这不是视觉还原承诺。新的行、缩进与表面规范由 `--cv-*` 统一管理。

## 后续优化（2026-10-10，未发布）

- 保留正文字号和400字重。英文可使用本机 Anthropic Sans；它不含中文，显式中文回退优先于通用系统字体。
- 过程标签和目标统一使用 `--cv-process-text`（浅色 #73736f / 深色 #999990），正文主色和展开思考不跟随变淡。
- 会话文件卡片展示摘要、前三个文件和剩余文件入口；审阅已有工具编辑片段。缺少差异时不伪造红绿行数；累计片段行数不是工作区净差异。不新增真实撤销操作。
- 原版视图缺陷必须通过禁用ClearView的对照和独立样式检查定位，不能靠阅读区CSS强行覆盖原版。已确认结果见 diagnostics/2026-10-10-native-chat-compat.md。

- 流式内容仅使用 `data-reader-streaming`，避开宿主主题的通用字符高亮接管。思考仍保留原动效和128px跟随视口；验证必须包含CSS Highlight实际着色，不能只检查元素opacity。
