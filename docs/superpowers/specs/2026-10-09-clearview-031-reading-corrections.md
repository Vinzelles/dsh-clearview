# ClearView 0.3.1 阅读修正

本说明记录用户在 0.3.0 安装后提出的四项修正，优先于 0.3.0 规格中「16px 正文」「完成后不折叠」「根区域独立底色」的旧约定。

- 正文使用宿主字号，不额外放大。保留主文字色、段落间距及衬线/界面字体分工。
- 保留整轮过程折叠。完成后默认收起，单行摘要显示完成状态、用时、步骤与工具调用数量，以及明确的展开入口。最终回答、用户输入、错误/中断提示不隐藏；中断/错误的过程默认展开。
- 自动完成不能打断过程中的真实选区或焦点。当前主动收起生效，恢复运行后的新阅读意图不能被旧收起记录覆盖。点击摘要时的焦点转移不能反转这次点击。
- 过程展开/收起保留原有 DOM、工具详情和流式阅读状态，继续使用现有 260ms/200ms 结构动效。工具与思考仍分行。
- 计划勾使用固定大小 SVG，方框为 border-box，实际中心横纵误差均不超过 0.5px。
- 阅读根背景透明；局部控件仍可有底色与边框。

验证包括默认折叠、保留回答、反复切换、同轮恢复后的选读保护、焦点移向摘要后的真实关闭、宿主字号变化、深浅色/480px，以及实际 SVG 中心位置。真实会话检查只读，不发送消息或创建会话。

已安装基线为 `plugin-38494fe3-e2a3-4651-ab33-3c520251a968`（0.3.0）。0.3.1 完成验证与候选准备后，再由用户确认发布/应用。
